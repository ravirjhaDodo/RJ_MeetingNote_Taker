Meeting notes basics

Panel A: original speech. Panel B: translated preferred language. Ask in English during the meeting.

New meeting vs continue

New meeting clears the workspace so you can capture a separate session. Start listening when notes already exist asks whether to continue the current meeting or start new (clear and listen). Clear works like New meeting.

Panel B and saved meetings

In Panel B, choose Translated transcript language (e.g. Hindi or Bengali), set Speaker gender for each person when shown, then press Translate Panel B. Use the saved-meetings dropdown to load a cloud meeting.

Mixed (English, Hindi, Hinglish)

Use Mixed — English, Hindi, Hinglish when people code-switch between English and Hindi. Other languages are not supported in Mixed — choose that language from the list instead.

High-accuracy Hindi

Choose Hindi as listen language, enable High-accuracy Hindi (pinned language), then start listening. Draft segments appear every ~40s; press Stop for the best full pass. Name speakers in the Speakers panel for better name accuracy.

Multi-speaker mode

Enable Multi-speaker (AssemblyAI) to label different voices automatically. Rename speakers in the Speakers panel or by clicking a speaker pill — the new name applies everywhere in the meeting.

For English meetings, set Expected speakers close to the real participant count before starting. Use Auto detect (up to 8) when you do not know the count; AI will identify the speakers it hears up to that limit. After capture, use Clean labels, then rename Speaker 1 / Speaker 2 to real names.

Capture source

Choose Capture source before listening:

  • Microphone — close talk — in-person or you near the mic.
  • Microphone — room / passive listening — best web workaround for Teams/Zoom desktop: laptop mic input + Jabra/speaker output.
  • Meeting audio — this device — online meeting on this computer (one-time share prompt on your machine).
  • Both — mic + meeting audio — recommended for online meetings on this computer.

Room and meeting-audio modes require Multi-speaker (AssemblyAI).

Recommended same-PC Teams/Zoom desktop setup

  1. Set speaker/output to Jabra or external speakers.
  2. Set microphone/input to the laptop microphone, not the Jabra mic.
  3. Choose Room listening — speakerphone / speakers.
  4. Enable Multi-speaker.
  5. Turn speaker volume up enough for the laptop mic to hear clearly.
  6. After capture, use Clean labels, then rename speakers if diarization still mixed a few turns.

This is an acoustic workaround. The planned desktop app will capture system audio directly for cleaner same-PC Teams/Zoom capture.

Room listening languages

  • English meetings: use Room listening + English + Multi-speaker. This is the best current web setup.
  • English + Hindi / Hinglish: live room capture is experimental. Mixed mode can miss Hindi from speaker playback; Hindi mode may catch both languages but may need cleanup.
  • Hindi-heavy meetings: use High-accuracy Hindi or import a Teams/Zoom transcript when accuracy matters.

No browser-only room-listening mode gives perfect Hindi/Hinglish text and perfect speaker labels from speaker playback. Rename speakers after capture or import the meeting transcript for cleaner labels.

Import transcript

Upload a Teams or Zoom .vtt or .txt export under Fallback capture to load speaker-labeled lines into your notes.

Mixed language

Use Mixed — English, Hindi, Hinglish only as a best-effort live mode. For English-only meetings, choose English. For Hindi-heavy meetings, choose Hindi with High-accuracy Hindi or use transcript import.
