# Signup and UserID

## UserID rules

- 3–24 characters
- Lowercase letters, numbers, underscore
- Must start with a letter
- Must be unique

## Contact email

Your contact email is used for notifications and recovery. **The same email can be used for multiple accounts** if each has a different UserID.

## Approval

New signups are **pending** until an admin approves them for cloud features. AI meeting notes trial starts immediately for 7 days.

## Password

Minimum 8 characters with at least one letter and one number. Use show/hide toggles on all password fields.
