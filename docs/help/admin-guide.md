# Admin guide

## User approval

Approve, reject, pause, or revoke accounts from the Admin page in the app.

## Plans

Set user plan to **free**, **paid**, or **byok** (bring your own key).

## Per-feature access {#feature-access}

Extend, pause, or resume each feature independently:

- AI meeting notes
- Cloud Q&A
- Cloud embeddings
- Auto-translate

Use amount + unit: days, weeks, months, or years.

## Guest access

Legacy guest API access grants temporary platform API use (separate from per-feature flags).

## Owner account

Platform owner UserID: `ravirjha`. Seed via `node scripts/seed-platform-owner.js` when setting up a new environment.
