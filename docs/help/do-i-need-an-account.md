# Do I need an account?

## Without an account (guest)

You can use the meeting app for:

- Live speech capture and structured notes
- Search within the current meeting
- Export transcript (TXT, Markdown, JSON, Word, SRT)

## With an account

| Feature | Account |
|---------|---------|
| AI meeting notes (7-day trial on signup) | Yes |
| Cloud save and embeddings | Yes (admin approval or paid/BYOK) |
| Cloud Q&A on saved meetings | Yes (admin approval or paid/BYOK) |
| Auto-translate via cloud | Yes (admin approval or paid/BYOK) |
| Profile and BYOK API keys | Yes |

## AI meeting notes {#ai-notes}

Guests see **Create meeting notes** disabled with a signup prompt. Signed-in users get a **7-day AI notes trial** when they register. After that, an admin can extend access.
