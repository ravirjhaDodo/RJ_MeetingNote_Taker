# Getting started

RJ Meeting Notes Taker captures live speech, organizes notes into decisions and action items, and can generate AI meeting notes when you finish.

**Developers / Codex:** see [`CODEX.md`](../../CODEX.md) in the project root for technical architecture.

## Quick paths

- **Try without account:** open [app.html](/app.html) from the home page.
- **Sign up:** create a UserID and password on the signup page.
- **Log in:** use your UserID (not your contact email) on the login page.
